## Getting Help

1. Check the [documentation](https://docs.tribewarez.com) first
2. Search existing [issues](https://github.com/TribeWarez/pot-o-validator/issues) for similar problems
3. Open a new issue with the `question` label
4. For security issues, see [SECURITY.md](SECURITY.md)

## Configuration

See `config/default.toml` for all available configuration options. Most settings can be overridden via environment variables — see `src/config.rs` for the full list.
